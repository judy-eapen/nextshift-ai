# NextShift AI — 5-minute demo script

*Record at http://localhost:8599 (`streamlit run ui/app.py`). Have the PM composite run pre-warmed once so the embedding caches are hot. Sidebar → "Simulate a source outage" is your failure demo. Speak the bold lines; the rest is what to click.*

| Time | On screen | Say |
|---|---|---|
| 0:00 | Start screen | **"Students don't know which fields will still offer real work. Professionals don't know if their role shrinks, how it changes, or what to learn. The data exists — BLS projections, O\*NET task lists, Anthropic's data on what AI is actually used for, prediction markets — but nobody assembles it for one person, and nobody says how sure they are. NextShift does, and it never promises a job is safe."** |
| 0:30 | Click *Start planning →*. Type **Product Manager**; week: *user research, writing requirements, prioritizing with engineering, stakeholder alignment*; industry *real-estate software*; tick *demand · change · learn*; horizon *next 1–2 years* | **"Four short turns, in plain language. Titles are ambiguous, tasks aren't — so it asks what my week actually looks like."** |
| 1:00 | Understanding gate | **"Before it spends a single tool call, the agent tells me what it understood — and here's the interesting part: the US occupation taxonomy has no Product Manager. So it assembled one from 23 real task statements across 14 official occupations, and shows me. I can untick anything that isn't my week."** Untick one task. **"That's the first human gate. Reject here and nothing runs."** Click *That's right — analyze*. |
| 1:40 | Working panel streaming | **"Now it gathers in parallel: BLS employment projections, which of my tasks AI is already used for, what forecasters expect about AI progress. Then it writes a plan, and a second model from a different family checks every line against the evidence."** (~2 min — cut to the result.) |
| 2:00 | Result: direct answer + §1 Outlook | **"It leads with the answer. Then the outlook — and look at the honesty: no official projection exists for my job, so it shows the closest categories and labels them proxies. Demand reading comes from BLS only; the AI-change reading is marked as our interpretation."** |
| 2:35 | §2 How the work may change | **"Three groups. 'AI will probably assist' is a fact about current use — user-feedback analysis, competitor research already heavy. 'May become more important' is an interpretation, and each one carries its reason: accountability, judgment, relationships. And a group we simply call uncertain. We never say a task disappears."** |
| 3:05 | §3–§4 For you · 30 days / 6 months / 1 year | **"Personalized to real-estate software and my week. Thirty-day actions are things I can actually finish: run one roadmap prioritization with an AI assistant and my usual method side by side, document where human judgment was essential."** |
| 3:30 | §6 Confidence · open *7 How we reached this answer* | **"Strong evidence, interpretation, unknowns, disagreement — forecasters put 22% to 39% on AGI by 2030, shown side by side, never averaged. And all the machinery is here if you want it: sources, the reviewer's removed lines, the evidence cards."** |
| 3:55 | *Start over* → **I'm exploring careers**. Answer two or three questions live ("editing videos for friends, organizing the charity drive…"), press **I'm not sure** once, then **Recommend careers now** → understanding gate → (cut to pre-recorded results) | **"Second door: a student who has no idea what they want. It interviews — one question at a time, picking the next question from what's still unclear — then shows what it understood before it touches any data. Then ten directions in three groups, each with the student's own words as the reason, official outlook, education, and an honest 'possible mismatch'. The student reacts, it narrows to a shortlist, and the deep dive ends with cheap ways to test the career before committing."** |
| 4:30 | Plan gate → *Approve & save* → saved screen | **"Nothing is written until I approve. Save, and the next run shows what changed."** |
| 4:40 | Architecture diagram | **"LangGraph supervisor, 14 nodes, two interrupts, four parallel gatherers, ten tools, SQLite memory, a reviewer on a different model family. Thirty-six end-to-end evals — twelve professional, twenty-four student with simulated students; both gates, injected failures — all pass. Roadmap: adjacent careers from O\*NET skill similarity, learning paths, alerts when a snapshot moves. Runs entirely on open-weight models for about a cent a plan."** |
